## 4) الموضوعات الممتدّة عبر المناطق (Cross-cutting)

1. **الكود الميت/المعلّق** — من المرحلة 1 إلى 5 يتصاعد (dropdown 178 ← viewer 1400) ثم ينقطع فجأة في admin. القاعدة «لا كود ميت» مطبقة فقط في المنطقة الأخيرة.
2. **هجر عقد SSOT** — المسارات (ROUTES)، الألوان (CSS vars)، روابط الصور (image-helpers)، الأنواع (AUDIO_TYPES/translate)، ثوابت ميتة — نمط واحد يتكرر في 5 مناطق.
3. **الطبقة الخادمية محكمة، والعميلة متروكة** — الـ API (المرحلة 4) نظيفة بنيوياً (Layering صحيح، 91/129 فحص مدير) بينما واجهة المشاهد تفتقر للتنظيف.
4. **نظاما API متوازيان** — `apiClient` (قديم؟) و`apiFetch` (معياري): التعايش في media-selector-modal يحتاج حسم.
5. **إفصاح/تعريب الأخطاء** — `handleRouteError` يصدّر الخام → يصل إلى toast/بانرات في 3 مناطق.
6. **فصل سمة الإدارة يعمل** — `.admin-layout` نطاقية (+admin-raised/sunken) مقابل تسرب ألوان حرفية في كلا الـ UI.
7. **توثيق** — admin ملتزم؛ viewer/روابط API مفقودة؛ وقليل من TSDoc الإنجليزي.

## 6) ما يحتاج تأكيداً قبل أي إصلاح (Open Questions)

1. `"track"` في album-player — نوع حقيقي في DB أم بقايا؟ (يحدد اتجاه إصلاح `AUDIO_TYPES`).
2. `excludeTypes: "season,episode,series_sports,series_deen"` — هل توجد قائمة أنواع معتمدة مركزيّة؟
3. الهوكان SSE هل يُركّبان على نفس الشاشة؟ (يحدد وزن `06` M3).
4. `tags` من `genres` في ItemManagementDialog — نفس الحقل أم مختلفان؟
5. `apiClient` مقابل `apiFetch` — أيهما المعتمد رسمياً (يُسحب منهما كاستنتاج نهائي)؟
6. نية `text-yellow-400` في تقييمات المشاهد — token موحّد أم لون عابر؟
7. `current.href` في hero (exclusive_items) — هل يخضع لقواعد `buildMediaUrl`؟
8. MediaCard مقابل UnifiedCard — توحيد أم تمييز مقصود؟
